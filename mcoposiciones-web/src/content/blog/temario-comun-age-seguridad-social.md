El temario común de AGE y Seguridad Social es una de las razones por las que muchos opositores se plantean preparar ambas oposiciones. Tiene sentido: si una parte importante de la base administrativa se comparte, puede ser más eficiente estudiarla una sola vez y abrir dos opciones.

Pero hay que matizar. Que exista temario común no significa que las oposiciones sean iguales. Tampoco significa que puedas preparar dos procesos sin más esfuerzo. La preparación conjunta funciona cuando se separa con claridad lo común, lo propio de AGE y lo propio de Seguridad Social.

En esta guía te explico cómo entender ese temario común y cómo usarlo sin caer en el caos.

## Qué significa temario común

Cuando hablamos de temario común, nos referimos a materias administrativas que aparecen en ambas preparaciones o que tienen una base muy aprovechable. Suelen incluir Constitución, organización del Estado, procedimiento administrativo, régimen jurídico, función pública, igualdad, transparencia, protección de datos y administración electrónica.

Estas materias construyen una base útil para cualquier oposición administrativa. Si entiendes bien procedimiento administrativo, no lo entiendes solo para AGE o solo para Seguridad Social. Entiendes cómo actúa la Administración, qué efectos tienen los actos, qué recursos existen y cómo se tramitan determinados procedimientos.

Esa base común es valiosa. Pero debe estudiarse bien.

## Lo común no es lo fácil

Un error frecuente es pensar que el temario común es la parte sencilla. No siempre. Procedimiento administrativo, función pública o administración electrónica pueden ser densos y muy preguntables.

La ventaja no es que sean materias fáciles. La ventaja es que el esfuerzo puede servir para más de una oposición. Por eso conviene trabajarlas con profundidad, no como una lectura rápida.

Si estudias la base común de forma superficial, no estarás aprovechando nada. Estarás creando una falsa sensación de avance.

## Qué parte es propia de AGE

En [Administrativo del Estado](/oposiciones-administrativo-estado/), además de la base común, debes trabajar el enfoque propio de AGE y la ofimática. Esta parte no puede dejarse para el final.

La ofimática es una diferencia importante. Word, Excel, Access, Outlook o Windows pueden aparecer con preguntas muy concretas. Usar estas herramientas en la vida diaria no equivale a prepararlas para un examen.

También hay materias y enfoques específicos del programa de AGE que deben trabajarse con test y simulacros. Por eso, aunque compartas base con Seguridad Social, AGE necesita su propio espacio semanal.

## Qué parte es propia de Seguridad Social

En [Seguridad Social](/oposiciones-seguridad-social/), la parte específica tiene mucho peso. Afiliación, altas y bajas, cotización, recaudación, prestaciones y procedimientos propios requieren un estudio aplicado.

Además, el supuesto práctico obliga a usar la teoría en casos. No basta con memorizar requisitos o definiciones. Hay que entender situaciones y consecuencias.

Si vienes de AGE, puedes tener una base administrativa útil. Pero eso no sustituye el trabajo específico de Seguridad Social. La preparación debe reservar tiempo para casos, test por bloques y corrección razonada.

## Cómo organizar una preparación conjunta

Una preparación conjunta AGE y Seguridad Social debería tener tres zonas:

1. Base común.
2. Bloque propio de AGE.
3. Bloque propio de Seguridad Social.

El problema aparece cuando todo se mezcla. Si una semana estudias un poco de cada cosa sin criterio, puedes sentir que avanzas, pero también puedes perder foco.

Una organización más clara sería:

- días o bloques para temario común;
- un bloque fijo de ofimática AGE;
- un bloque específico de Seguridad Social;
- test diferenciados;
- repasos de base común;
- simulacros separados cuando haya materia suficiente.

La clave no es hacerlo todo a la vez. Es hacerlo con orden.

## Cómo repasar la base común

El repaso de la base común debe estar programado. Si estudias Constitución, procedimiento o función pública una vez y después no vuelves, ese conocimiento se debilita. La ventaja del temario común solo aparece cuando lo mantienes vivo.

Una forma útil de repasar es alternar:

- test cortos de temas ya vistos;
- lectura de esquemas;
- revisión de errores;
- preguntas acumulativas;
- repasos antes de entrar en bloques específicos.

No hace falta que todos los repasos sean largos. A veces veinte minutos bien dirigidos evitan olvidar un concepto clave. Lo importante es que el repaso no dependa de si sobra tiempo, porque normalmente no sobra.

También conviene que los errores comunes se corrijan con una mirada amplia. Si fallas una pregunta de procedimiento en AGE, ese fallo también puede afectar a Seguridad Social. Corregir bien una vez puede mejorar dos preparaciones.

## Ejemplo de semana con temario común

Un ejemplo de semana para una preparación conjunta podría ser:

- un bloque de temario común;
- un bloque de test acumulativo;
- un bloque de ofimática AGE;
- un bloque de Seguridad Social específica;
- un bloque de supuesto o caso corto;
- un repaso breve de errores.

Este esquema debe adaptarse a cada persona. Quien trabaja quizá necesite una versión más ligera. Quien tiene más disponibilidad puede ampliar simulacros y repasos. Lo importante es mantener presencia de las tres zonas: común, AGE y Seguridad Social.

Si una semana solo avanzas en lo común y abandonas lo específico, el plan se desequilibra. Si haces muchos supuestos pero no repasas base administrativa, también. La preparación conjunta exige una revisión frecuente para no perder foco.

## Cuándo tiene sentido preparar ambas

Preparar ambas oposiciones puede tener sentido si:

- tienes disponibilidad semanal suficiente;
- puedes seguir una planificación;
- quieres ampliar oportunidades;
- no te bloquea trabajar materias distintas;
- tienes una base o estás dispuesto a construirla con calma.

No tiene tanto sentido si apenas tienes horas, si todavía no has creado hábito de estudio o si preparar dos caminos te genera ansiedad constante.

En esos casos, puede ser más prudente empezar por una oposición y valorar la segunda después.

## Ventajas de aprovechar el temario común

La principal ventaja es eficiencia. No duplicas el estudio de la base administrativa. Si trabajas bien Constitución, procedimiento o función pública, ese conocimiento puede ayudarte en ambas.

La segunda ventaja es estratégica. Preparar dos oposiciones puede ampliar opciones, especialmente cuando las convocatorias tienen calendarios o ritmos distintos.

La tercera ventaja es que la base común te da más cultura administrativa. Eso mejora la comprensión de los bloques específicos.

Pero estas ventajas solo aparecen si el plan está bien diseñado.

## Riesgos de preparar ambas sin método

El riesgo más habitual es acumular materiales. Dos temarios, dos calendarios, dos listas de test, dos tipos de simulacro. Si no hay estructura, el opositor se siente siempre atrasado.

Otro riesgo es no profundizar en lo específico. Puedes estudiar mucha base común y dejar AGE sin ofimática suficiente o Seguridad Social sin supuesto práctico.

También puede pasar lo contrario: saltar demasiado pronto a lo específico y no consolidar la base administrativa.

La preparación conjunta exige equilibrio.

## Si no sabes si te conviene

Si tienes dudas, mira tu situación real:

- cuántas horas puedes estudiar;
- si trabajas;
- si tienes base jurídica;
- si la ofimática te preocupa;
- si los casos prácticos te resultan difíciles;
- si necesitas una preparación muy guiada.

No elijas el pack conjunto solo porque parezca más completo. Elige si puedes sostenerlo. Una buena decisión debe darte claridad, no presión.

## Cómo decidir prioridades cada mes

Aunque el plan semanal esté bien diseñado, conviene revisar prioridades cada cierto tiempo. La preparación conjunta no permanece igual desde el primer mes hasta el final. Al principio puede pesar más la base común. Después quizá necesites reforzar ofimática, introducir más supuestos o aumentar test acumulativos.

Una revisión mensual puede responder a preguntas sencillas:

- qué bloque ha avanzado menos;
- qué errores se repiten;
- qué materia está generando más dudas;
- si el repaso está funcionando;
- si la carga semanal sigue siendo realista.

Esta revisión evita estudiar por inercia. No se trata de cambiar de plan cada semana, sino de ajustar con criterio. Si AGE empieza a quedarse sin ofimática, se corrige. Si Seguridad Social acumula teoría sin casos, se incorporan supuestos. Si la base común se olvida, se refuerzan repasos.

La preparación conjunta funciona mejor cuando el plan se observa y se corrige. Esa es una de las ventajas de trabajar con seguimiento: no esperar a estar perdido para reorganizar.

## Conclusión

El temario común AGE y Seguridad Social es una oportunidad para estudiar con más eficiencia, pero no elimina la necesidad de planificación. Lo común debe trabajarse bien. Lo específico debe tener su espacio. Y los repasos deben estar programados.

Preparar ambas oposiciones puede ser una estrategia inteligente si tienes disponibilidad y método. Si no, es mejor decidir con calma y no convertir la preparación en una carga imposible.
